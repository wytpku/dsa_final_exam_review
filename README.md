# DSA 期末刷题

在 Finder 中双击 `启动刷题.command`，浏览器会打开 [本地刷题网站](http://127.0.0.1:8787/)。也可以在本目录运行 `python3 serve.py`。网站可离线练习，关闭终端后可通过同一个入口重新启动。

- 可同时按知识点、题目来源和做题状态筛选。点击题卡上的知识点标签也能直接筛选，题目列表可按题名、来源、原题号或知识点搜索。
- 选择、判断和可核验的填空题自动判分。答对后自动进入当前题组的下一题，答错后可留在原题订正。
- 开放题提交后显示参考解答，选「自评答对」即可记录完成并自动进入下一题。
- 进度和草稿保存在当前浏览器资料中。每次用同一个浏览器资料打开上面的固定地址，都会恢复上一次的题目与作答状态。

## 题库范围

题库共 401 道练习，覆盖 48 个知识点，其中 158 道支持自动判分。题卡标明来源、原题号和页码，开放题提供参考解答供自评。
